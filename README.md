# WBC Classification

A CNN-based deep learning project for classifying white blood cell images.

## Classes

- Neutrophil
- Lymphocyte
- Monocyte
- Eosinophil
- Basophil

## Method

- Resize images to 128x128
- Normalize pixel values
- Apply data augmentation
- Train a CNN classifier
- Evaluate using accuracy, classification report, and confusion matrix

## Baseline Result

Test Accuracy: 89.74%
